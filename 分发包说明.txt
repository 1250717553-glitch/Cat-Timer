桌面宠物计时器 · 源码分发包
================================================

一只橘猫常驻桌面，帮你盯着喝水和久坐。

【重要】这一份是「源码包」，不是装好的程序。
        第一次启动会自动下载依赖（约 100MB），需要联网。


------------------------------------------------
Windows 用户
------------------------------------------------

1. 先装 Python（如果还没装）
   下载：https://www.python.org/downloads/
   版本：3.10 以上（推荐 3.12）
   安装时**务必勾选** "Add Python to PATH"

2. 双击   启动程序.bat
   第一次会自动创建环境并装依赖，等 1-3 分钟
   之后再双击就是秒开

如果窗口一闪而过，说明出错了：
    用「命令提示符」进入这个文件夹，手打   启动程序.bat
    这样能看到完整错误信息。


------------------------------------------------
Mac 用户
------------------------------------------------

1. 先装 Python（如果还没装）
   Mac 自带 Python 3，但版本可能太旧。建议装新版：
   下载：https://www.python.org/downloads/macos/
   或者用 Homebrew：brew install python

2. 打开「终端」，进入这个文件夹，执行：
       bash 启动.sh
   
   （第一次要先给执行权限：chmod +x 启动.sh）

3. 第一次会自动创建环境并装依赖，等 1-3 分钟
   之后再运行就是秒开。

如果提示 "cannot be opened because it is from an unidentified developer"：
    右键点击 启动.sh，选择「打开」，再确认一次即可。
    （这是 macOS 对所有未签名脚本的标准提示，不是病毒。）


------------------------------------------------
启动后怎么用
------------------------------------------------

程序启动后没有窗口，只在右上角（Mac）或右下角（Windows）
的系统托盘/菜单栏出现一个猫头图标。

双击猫头        → 打开管理窗口
右键猫头        → 菜单（新增、显示范围、开机自启、退出）
桌面上会出现    → 一只橘猫 + 计时卡片

轻点猫          → 卡片收起/展开
拖动猫或卡片    → 移动位置（会自动记住）


------------------------------------------------
Mac 版的功能差异（重要）
------------------------------------------------

以下功能在 Windows 上可用，Mac 上暂不可用或行为不同：

  开机自启        Mac 上写的是 ~/Library/LaunchAgents 的 plist，可用
  提示音          Mac 上用系统自带 afplay 播放，可用
  全屏自动隐藏    Mac 上没有等价的系统 API，只能检测「前台应用是否全屏」，
                  精度不如 Windows，可能偶尔判断不准
  托盘图标        Mac 上是菜单栏图标，会显示为单色模板图（系统限制，
                  macOS 菜单栏不显示彩色图标）
  窗口阴影/圆角   由 macOS 窗口系统决定，视觉效果可能与 Windows 略有差异


------------------------------------------------
数据存在哪里
------------------------------------------------

Windows：  %AppData%\桌面宠物计时器\config.json
Mac：      ~/Library/Application Support/桌面宠物计时器/config.json

这是纯文本 JSON，可以直接备份或复制到另一台电脑。
配置文件损坏时会自动备份成 config.corrupt-时间戳.json。


------------------------------------------------
卸载
------------------------------------------------

Windows：删掉整个文件夹即可（没有写注册表，除非你开过「开机自启」）
Mac：    删掉整个文件夹；
         如果开过开机自启，再执行：
             rm ~/Library/LaunchAgents/com.cat-timer.desktop-pet-timer.plist


------------------------------------------------
遇到问题
------------------------------------------------

1. 启动错误.log    这个文件里有崩溃详情（自动生成）
2. 如果是「ModuleNotFoundError: PySide6」
   → 依赖没装成功，手动执行：
       Windows:  .venv\Scripts\pip install -r requirements.txt
       Mac:      .venv/bin/pip install -r requirements.txt

3. 如果想用打好包的版本（不用装 Python）：
   去 GitHub Releases 下载 Setup.exe（仅 Windows）
   https://github.com/1250717553-glitch/Cat-Timer/releases
